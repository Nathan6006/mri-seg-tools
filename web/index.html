Add scans

Choose one scan folder or many — each folder is one mouse at one timepoint, exactly as it came off the scanner, with its DICOM sub-folder inside. Add folders as many times as you like; they queue up and run together.

Nothing is uploaded. The scans are read and segmented inside this browser tab, on this machine. No image data is sent anywhere, which is why this page is safe to open from a shared link.

Draw two slices a few apart, then Interpolate fills in the ones between by blending the two shapes. Faster than tracing every slice when a tumour spans several.

The coronal and sagittal panes are reformats of the axial stack, not the separately acquired coronal scan — so they always line up with the mask. They are for looking and navigating; painting happens in the axial pane, because a whole slice of tumour is only one row tall over there.

Level and window change only how the scan is displayed. They never affect the mask or the volume.

Where things live

This page has no server. Scans are read and segmented in this tab and results are stored in this browser, on this machine — nothing is uploaded and nothing is written to a folder. Use Download all for a copy you control.

ITK-SNAP

A web page cannot launch another program — that is the browser sandbox, and no setting changes it. What it can do is share a folder.

On Chrome or Edge: press ITK-SNAP folder… and pick a directory once. Download for ITK-SNAP then writes a scan straight into it, you open the .itksnap workspace from there, and Check folder for edits reads your corrections back with one click.

On Firefox or Safari: the folder API does not exist, so Download for ITK-SNAP gives you a zip. Unzip it, work on it, then Import corrected masks and select the edited _tumor.nii.gz files.

Either way the original automated mask is kept untouched and both volumes are reported separately. Note that macOS does not associate the .itksnap extension, so use File > Open Workspace in ITK-SNAP, or set Open With on the file once in Finder.
